## Problem Statement

<div class="header"><div class="title">F. Deglado</div><div class="time-limit"><div class="property-title">time limit per test</div>2 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>512 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>  </p><p>You are given a $$$2n \times 2n$$$ grid $$$a$$$ where each column is a permutation$$$^{\text{∗}}$$$ of length $$$2n$$$.</p><p>We want to sort all columns in ascending order from top to bottom by performing the following operation: </p><ul> <li> Choose a $$$2 \times 2$$$ subgrid and swap the two top elements with the two bottom elements.<p>More formally, you can choose two integers $$$i$$$ and $$$j$$$ ($$$1 \leq i, j  \lt  2n$$$), then swap $$$a_{i,j}$$$ with $$$a_{i+1,j}$$$ and swap $$$a_{i,j+1}$$$ with $$$a_{i+1,j+1}$$$. </p></li></ul><p>You have to sort all columns using at most $$$n \cdot \binom{2n}{2} + 9n$$$ operations, or determine that it is impossible.</p><p>Note that you do <span class="tex-font-style-bf">not</span> need to minimize the number of operations.</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$A permutation of length $$$m$$$ is an array consisting of $$$m$$$ distinct integers from $$$1$$$ to $$$m$$$ in arbitrary order. For example, $$$[2,3,1,5,4]$$$ is a permutation, but $$$[1,2,2]$$$ is not a permutation ($$$2$$$ appears twice in the array), and $$$[1,3,4]$$$ is also not a permutation ($$$m=3$$$ but there is $$$4$$$ in the array).</p></div></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. The first line contains the number of test cases $$$t$$$ ($$$1 \le t \le 500$$$). The description of the test cases follows.</p><p>The first line of each test contains a single integer $$$n$$$ ($$$1 \leq n \leq 80$$$).</p><p>The $$$i$$$-th line of the next $$$2n$$$ lines contains $$$2n$$$ integers $$$a_{i,1},a_{i,2},\ldots,a_{i,2n}$$$ ($$$1 \leq a_{i,j} \leq 2n$$$) — the elements of the $$$i$$$-th row of the grid.</p><p>It is guaranteed that every column in the grid forms a permutation of length $$$2n$$$.</p><p>It is guaranteed that the sum of $$$n^3$$$ over all test cases does not exceed $$$80^3$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, if it is impossible to sort all columns in at most $$$n \cdot \binom{2n}{2} + 9n$$$ operations, print $$$-1$$$ in a single line.</p><p>Otherwise, in the first line print a single integer $$$k$$$ ($$$0 \leq k \leq n \cdot \binom{2n}{2} + 9n$$$) — the number of operations.</p><p>Then $$$k$$$ lines follow, the $$$w$$$-th line containing two integers $$$i_w$$$ and $$$j_w$$$ ($$$1 \leq i_w, j_w  \lt  2n$$$) — you choose $$$i_w$$$ and $$$j_w$$$ in the $$$w$$$-th operation.</p></div><div class="sample-tests"><div
